

# Step 1: Install GitHub CLI

Run one of the following commands in your Windows PowerShell terminal depending on your package manager:

- **Using WinGet (Default Windows Package Manager):**
    ```powershell
    winget install --id GitHub.cli
    ```

- **Using Chocolatey:**
    ```powershell
    choco install gh
    ```

- **Using** Scoop**:**
    ```powershell
    scoop install gh
    ```


_Alternatively, you can download and run the `.msi` installer directly from the official [GitHub CLI Releases](https://github.com/cli/cli/releases) page._
